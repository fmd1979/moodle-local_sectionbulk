# Moodle Marketplace submission notes

## Listing name
**Bulk Sections & Quizzes Manager**

## Component
`local_sectionbulk`

## Plugin type
Local plugin

## Short description
Safely preview and apply bulk changes to Moodle course sections and quizzes by course IDs or category, including availability dates, profile/completion restrictions, section creation, quiz dates, attempts, and grading methods.
